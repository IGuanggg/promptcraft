# PromptCraft · AI 视觉提示词工作台

把一句模糊的画面想法，整理成可直接投喂给绘图模型的结构化提示词。纯前端、离线运行、不联网、不上传任何数据。

## 为什么做这个

写提示词时最费时间的不是创意，而是把「想要什么」拆成模型能读懂的字段：主体、风格、光照、镜头、画幅、负向约束。每次都要在脑子里重排一遍，还容易漏项。

PromptCraft 把这件事做成表单：选完六项，中英双语提示词和负向词同时生成，一键复制。

## 功能

- **六维表单**：主体 / 风格 / 光照 / 镜头 / 画幅 / 补充约束
- **双语输出**：中文描述给沟通用，English Prompt 给模型用，按 `--ar` 约定带比例
- **负向提示词**：内置一组通用负向词，规避低清晰度、畸形肢体、水印等常见问题
- **四组预设**：人像写真、产品棚拍、场景概念、海报主视觉，一键套用
- **实时统计**：字符数、词条数、预估出图耗时随输入变化
- **一键复制**：三段结果各自独立复制，带成功反馈

## 技术结构

纯静态站点，无框架、无构建、无后端：

```
promptcraft/
├── index.html        语义化结构 + 表单控件
├── style.css         深色界面、响应式双栏布局
├── app.js            DOM 绑定：读表单、渲染、剪贴板
├── lib/prompt.js     提示词拼装核心（UMD-lite，浏览器与 Node 共用）
├── tests/            node --test 单测
└── docs/             作品详情文档
```

拼装逻辑全部放在 `lib/prompt.js`：`buildZh` / `buildEn` 接收表单对象、返回字符串，不碰 DOM。同一份文件浏览器挂到 `window.PromptLib`，Node 用 `require` 加载，所以单测跑的是线上那份代码，不是副本。

剪贴板优先走 `navigator.clipboard`，非安全上下文（`file://`）降级到 `execCommand`，保证双击打开时复制按钮也不失效。

## 测试

```bash
npm test        # node --test，9 个用例覆盖拼装顺序、空字段、比例参数、词条统计
```

## 本地运行

```bash
# 任意静态服务器
cd promptcraft
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080
```

也可以直接双击 `index.html` 用浏览器打开。

## 使用建议

1. 先选预设逼近方向，再改主体描述
2. 「补充约束」写质感与氛围词（胶片颗粒、体积光、低饱和）
3. 负向词可按模型习惯删减，部分模型对负向词不敏感
4. 英文提示词用于可直接写英文的模型，中文提示词用于支持中文的国产模型
